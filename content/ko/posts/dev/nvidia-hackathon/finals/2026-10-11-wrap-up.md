본선이 끝나고 나흘 뒤, 마지막 결정을 내렸다. 무엇을 남기고 무엇을 지울 것인가.

---

## 배경: 약속 하나가 남아 있었다

예선 첫 통합 시험 때 키 규칙을 정하며 이렇게 말했었다. "재발급할게. 마무리 때 재발급 안내하도록 기록해둬." 키 사본은 설계된 주입 경로(게이트웨이의 자격 증명 저장소, 샌드박스 감독 프로세스, NemoClaw 설정)에만 두기로 했고, 그 대가로 대회가 끝나면 키를 폐기하기로 했다.

## 무엇을 했나

| 대상 | 처리 |
|---|---|
| NVIDIA API 키(예선·본선) | **폐기**(내가 직접) |
| Brev 클라우드 인스턴스 | **삭제**(내가 직접) |
| 본선 샌드박스·자격 증명 묶음·샌드박스 이미지 | 삭제 |
| 예선 샌드박스, OpenShell, NemoClaw | 제거 |
| 게이트웨이 상태 폴더, NemoClaw 설정, 봉인 자료 사본, `.env` | 삭제(내가 직접) |
| 해커톤용 Docker 이미지·컨테이너 | 삭제 |
| colima와 다른 프로젝트의 Docker 자료 | **유지** — 해커톤 전부터 쓰던 것 |
| 예선·본선 저장소 | **유지** — 공개된 결과물이자 기록 |

몇몇 삭제는 에이전트가 하지 않고 내가 직접 했다. 에이전트의 자동 승인 장치가 홈 폴더의 상태 폴더 삭제를 "되돌릴 수 없는 삭제"로 막았기 때문이다. 에이전트는 막힌 일을 우회하지 않고 정확한 명령을 넘겼고, 나는 그것을 직접 실행했다. 되돌릴 수 없는 일은 사람이 마지막 버튼을 누르는 구조가 맞다고 생각한다.

## 미뤄 둔 일은 미결로 닫는다

본선 상태 기록에는 미뤄 둔 일이 다섯 건 있었다. 작업 브랜치 정리, 화면 경고 목록 다듬기, 시연 스크립트의 시각 비교 여유, 공개 저장소의 화면 사진, 커밋 작성자 이메일 공개 문제다. 브랜치 정리만 하고 나머지는 **미결로 완료**시켰다. 예선 PR의 Codex 재검토도 하지 않기로 했다. 내 말은 "git에 추가 작업은 안 할 거야"였다.

## 선택지

| 안 | 판단 |
|---|---|
| 환경을 그대로 두기 | 버림 — 키 사본과 쓰지 않는 자원이 남는다 |
| 프로젝트 폴더까지 전부 삭제 | 버림 — 저장소에 없는 로컬 기록(실행 출력)이 사라진다 |
| 미뤄 둔 일을 마저 하기 | 버림 — 대회가 끝났고, 병합은 곧 공개다 |
| **실행 환경과 키 사본은 지우고, 기록은 남기고, 남은 일은 미결로 닫기** | **채택** |

## 정리하며 배운 것

정리 중에 Docker 가상 머신을 끌 때의 순서를 다시 지켰다. 게이트웨이를 먼저 멈춘 뒤 colima를 켜고, 해커톤 자료만 지우고, 일이 끝난 뒤에 껐다. 본선 전날 밤 colima를 켜자마자 꺼서 샌드박스가 Error에 갇혔던 일을 되풀이하지 않기 위해서였다.

## 돌아보며

두 번의 해커톤에서 가장 오래 남는 것은 코드가 아니라 결정하는 방식이었다.

- 평가를 먼저 고정하고, 결과를 본 뒤에는 규칙을 바꾸지 않는다.
- 모델에게 지시하는 대신 코드로 경계를 긋는다.
- 결정을 채팅이 아니라 기록으로 남긴다.
- 만들지 않은 것은 만든 것처럼 쓰지 않는다.
- 되돌릴 수 없는 일은 사람이 정한다.

이 시리즈도 그 기록을 바탕으로 썼다.
